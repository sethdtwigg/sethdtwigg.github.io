Google-style search over a legacy records system

DataWorks Plus

The main lookup screen was a form with hundreds of fields. Finding one record took several minutes of an officer’s time. I built a Lucene-backed search to replace the whole thing with a single query box.

Outcome A typical record lookup went from several minutes to seconds, and it became the search path agency users reach for first.

  • Lucene
  • C#
  • .NET
  • SQL Server

CI/CD pipeline

DataWorks Plus

Build and release was fully manual and took roughly two days. I designed and implemented an Azure DevOps CI pipeline, then automated deployment to a dedicated validation machine with post-deployment testing so installation defects surfaced before release rather than in the field.

Outcome Build-and-release time fell from about two days to under two hours. Production hotfixes dropped by approximately 40%.

  • Azure DevOps
  • Release engineering
  • Automated testing

Performance rebuild of hot-path modules

DataWorks Plus

02

Open source

Public repositories. VerseLink is one idea solved three times. You type a Bible verse reference, it becomes the full verse text, wherever you happen to be typing. Each platform fights you differently, so each version works differently underneath.

VerseLink for Windows

C++

Runs in the background on a global hotkey. Press it and the verse reference under your cursor becomes the full text, in whatever window has focus.

  • C++
  • Win32
  • Global hotkeys

VerseLink for Android

Kotlin

The same thing as a secondary keyboard. A custom input method that expands references inline in any app on the phone.

  • Kotlin
  • Android IME

PowerToys Run — VerseLink

C#

A PowerToys Run plugin. It types the verse text out as if it came from the keyboard, so it still works in applications that refuse pasted input.

  • C#
  • Plugin architecture

Treeology Daily

Progressive Web App

An installable PWA for daily catechism review, 91 questions in all. It runs fully offline behind a service worker, has quiz and reading modes, lets you set your own pace, and exports progress so you can move it to another device.

  • JavaScript
  • Service workers
  • Offline-first

AoE2 Traitor

Single-file web app

A party tool for Age of Empires II that assigns teams and secret traitors. All the shared state lives in the URL hash, so there is no backend and nothing to run. Built it for 4v4 nights on Discord.

  • JavaScript
  • URL-hash state

Event Pulse

Dart / Flutter

A small Flutter client that polls the Planning Center API and shows the most recent check-outs for an event.

  • Dart
  • Flutter
  • REST
